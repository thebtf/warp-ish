# Импорт из Warp на Windows

Откройте **Settings → Features → General → Import from Warp**. Кнопка читает локальные данные Warp Stable и открывает warp-ish с сохранённой раскладкой в новом профиле. Следующий обычный запуск warp-ish использует этот профиль после успешного восстановления окон.

Переносятся совместимые настройки, сохранённые окна, группы, вкладки, split-панели, рабочие каталоги и локальные шаблоны. В панелях запускаются свежие оболочки. Уже работающие процессы остаются в Warp. Для CLI-сессии используйте её команду возобновления. Команды в шаблонах выполняются при явном открытии соответствующего шаблона.

Чтобы вернуться к прежнему профилю warp-ish, сначала закройте warp-ish. В конфигурации импортированного профиля файл `warp-import-previous-profile` содержит имя прежнего профиля. Сохраните копию `%LOCALAPPDATA%\warpish\WarpIsh\config\active-import-profile` и запишите в него прежнее имя. Если прежнее имя пустое, вынесите файл `active-import-profile` из каталога конфигурации. Затем снова запустите warp-ish. Исходный Warp и данные обоих профилей сохраняются.
