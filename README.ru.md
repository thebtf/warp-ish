# warp-ish

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md)

warp-ish — локальный терминал для Windows 11 x64 на основе [Warp](https://github.com/warpdotdev/warp). Он работает офлайн, сразу открывает оболочку и обходится без учётной записи Warp.

## Возможности

- Запускайте PowerShell в окнах, вкладках и разделённых панелях. Доступны блоки команд и вывода, многострочный ввод, локальное автодополнение, поиск, копирование, вставка и темы.
- Нажмите стрелку вверх в строке ввода, чтобы открыть **HISTORY**. Команды можно отфильтровать и выбрать, а Esc вернёт черновик. Команды вроде `omp --resume …` сохраняются в обычной истории.
- Восстанавливайте окна, вкладки и панели вместе с рабочими каталогами. В панелях запускаются новые оболочки и ждут ваших команд.
- Запускайте OMP, SSH, Git и другие консольные программы обычным способом. Они сами управляют своими сессиями, настройками и подключениями к сети.

В терминале убраны встроенный AI Warp, учётные записи, облачная синхронизация, Drive, общий доступ и телеметрия. Данные warp-ish хранятся отдельно от данных Warp.

## Установка и запуск

1. Скачайте ZIP для Windows x64 в разделе Releases этого репозитория. Сверьте SHA-256 с заметками к выпуску или данными пакета.
2. Распакуйте весь архив в папку, в которую у вас есть право записи. Сохраните всё содержимое папки `app`, включая DLL и ресурсы.
3. Откройте `app/warp-ish.exe`. При необходимости создайте ярлык через контекстное меню EXE в Windows.

## Обновление и откат

- Для обновления закройте warp-ish, сделайте резервную копию его данных и распакуйте новый ZIP в отдельную папку. Запустите новый EXE под тем же пользователем Windows и с тем же профилем. Сохраните прежний пакет, пока не проверите настройки, историю и раскладку.
- Для отката закройте новую версию и сохраните отдельную копию её данных. Восстановите резервную копию, сделанную перед обновлением, и запустите прежний EXE. Порядок миграции и восстановления для конкретной версии указан в заметках к выпуску.

Для стандартного профиля warp-ish скопируйте существующие каталоги при закрытом приложении. Если есть ключ реестра `HKCU\Software\Warp.dev\WarpIsh`, включите его в резервную копию.

- `%USERPROFILE%\.warp-ish`
- `%APPDATA%\warpish\WarpIsh`
- `%LOCALAPPDATA%\warpish\WarpIsh`

## Исходники и лицензии

warp-ish — независимый форк [warpdotdev/warp](https://github.com/warpdotdev/warp). Точные коммиты Warp и форка, соответствующие исходники, контрольная сумма пакета и результаты проверок приводятся в заметках к конкретному выпуску.

Исходный код приложения распространяется по [AGPL-3.0](LICENSE-AGPL), библиотеки интерфейса Warp — по [MIT](LICENSE-MIT). Лицензии сторонних компонентов находятся в файле `app/resources/THIRD_PARTY_LICENSES.txt` внутри пакета.
