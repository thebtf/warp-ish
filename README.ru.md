# warp-ish

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md)

warp-ish — локальный терминал для Windows 11 x64 на основе [Warp](https://github.com/warpdotdev/warp). Он работает офлайн, сразу открывает оболочку и обходится без учётной записи Warp.

## Установка и запуск

1. Скачайте установщик для Windows x64 на [странице релизов GitHub](https://github.com/thebtf/warp-ish/releases) и сверьте SHA-256 с заметками к выпуску.
2. Запустите установщик. Он устанавливает программу для текущего пользователя Windows, по умолчанию в `%LOCALAPPDATA%\Programs\warp-ish`.
3. Откройте **warp-ish** из меню «Пуск».

В том же выпуске есть ZIP для запуска без установки. Распакуйте архив в папку, в которую можно записывать, и запустите `app/warp-ish.exe`. Храните содержимое папки `app` вместе.

## Перенос рабочего пространства из Warp

Откройте **Settings → Features → General → Import from Warp**. Импорт открывает новое окно и профиль warp-ish с совместимыми настройками, сохранёнными окнами, группами, вкладками, разделёнными панелями и рабочими каталогами из Warp Stable. Также переносятся шаблоны запуска, история команд PowerShell и сохранённый вывод завершённых локальных команд. После успешного восстановления окон следующий обычный запуск откроет импортированный профиль.

В импортированных панелях запускаются свежие оболочки. Нажмите стрелку вверх, чтобы открыть **HISTORY**, или запустите команду возобновления своего CLI, чтобы продолжить сессию. Повторный импорт создаёт ещё один профиль. [Импорт и возврат к предыдущему профилю](docs/warp-ish/WORKSPACE_IMPORT.md)

## Возможности

- Смотрите картинки прямо в терминале через Kitty Graphics, iTerm2 (OSC 1337) и SIXEL. Например, если установлен Chafa, выполните `chafa -f sixels photo.png`. Для Kitty программа передаёт данные изображения через свой вывод. Поддержка появилась в `0.2.0` на базе Warp `master @ 1c7fda1191`.
- Запускайте PowerShell в окнах, вкладках и разделённых панелях. Доступны блоки команд и вывода, многострочный ввод, локальное автодополнение, поиск и темы.
- Восстанавливайте раскладку терминала и рабочие каталоги. В восстановленных панелях запускаются новые оболочки и ждут ваших команд.
- Запускайте OMP, SSH, Git и другие консольные программы. При изменении размера панели с OMP, запущенным напрямую как `omp` или `omp.exe`, исправлено мерцание из-за повторного переключения экранов.
- Локальный агент может определить своё окно, группу вкладок, вкладку и панель, создать вкладку или разделить панель, запустить соседнюю сессию и отправить клавиши в нужную панель. Включите **Settings → Scripting → Local MCP control**, откройте новую панель и настройте клиент на запуск `warp-ish-mcp.exe` через stdio. Он находится рядом с `warp-ish.exe`. [Руководство по локальному MCP](docs/warp-ish/LOCAL_MCP.md)

В терминале убраны встроенный AI Warp, учётные записи, облачная синхронизация, Drive, общий доступ и телеметрия. Данные warp-ish хранятся отдельно от данных Warp.

## Обновление, переустановка и откат

- Для обновления или переустановки закройте warp-ish и запустите установщик нужной версии под тем же пользователем Windows. Если вы используете ZIP, распакуйте новую версию в отдельную папку. Настройки, история и раскладка хранятся вне папки установки и сохраняются при удалении приложения.
- Перед обновлением закройте warp-ish и сделайте резервную копию профиля. Для профиля по умолчанию скопируйте существующие каталоги из списка ниже и экспортируйте ключ реестра `HKCU\Software\Warp.dev\WarpIsh`, если он есть. Для импортированного профиля также сохраните его данные и файл выбора активного профиля. [Пути профилей](docs/warp-ish/WORKSPACE_IMPORT.md)
- Для отката закройте новую версию, отдельно сохраните её данные, восстановите резервную копию до обновления и запустите предыдущую версию. Указания по миграции и восстановлению для конкретной версии приведены в заметках к выпуску.

- `%USERPROFILE%\.warp-ish`
- `%APPDATA%\warpish\WarpIsh`
- `%LOCALAPPDATA%\warpish\WarpIsh`

## Исходники и лицензии

warp-ish — независимый форк [warpdotdev/warp](https://github.com/warpdotdev/warp). Точные коммиты Warp и форка, соответствующие исходники, контрольная сумма пакета и результаты проверок приводятся в заметках к конкретному выпуску.

Исходный код приложения распространяется по [AGPL-3.0](LICENSE-AGPL), библиотеки интерфейса Warp — по [MIT](LICENSE-MIT). Лицензии сторонних компонентов находятся в файле `resources/THIRD_PARTY_LICENSES.txt` рядом с EXE. Также доступны [исходный README Warp](README.upstream.md), [сведения о происхождении](docs/warp-ish/UPSTREAM.md) и [критерии приёмки](docs/warp-ish/ACCEPTANCE.md).
